A LITTLE MORE CONTEXT

Frequently asked questions

What is mind training? ＋

MyMind uses “mind training” as a convenient name for everyday practices that support attention, self-awareness, relaxation and healthy habits. It is not a single standardized medical treatment.

Is MyMind the same as brain training? ＋

No. MyMind brings meditation, breathing, sleep, movement, journaling, audio and other routines together. MindLubella’s cognitive exercises can be included as a separate training experience.

Can I build my own plan? ＋

Yes. In the demo you can schedule training activities and daily habits, check off completed steps and keep reflections.

Is this a finished app? ＋

This is an interactive frontend prototype intended to demonstrate the concept. It does not currently offer user accounts, cloud synchronization, clinical services, or a verified coach marketplace.
